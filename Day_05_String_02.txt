Q1. What is the difference between slice() and substring()?
  ANS: Both extract a portion of a string with (start, end) parameters.
       Key differences:
       - slice() supports NEGATIVE indices (counts from end);
         substring() treats negatives as 0.
       - If start > end: substring() swaps them; slice() returns "".
       - substr() is DEPRECATED — its second argument is LENGTH not end index.
       Recommendation: always use slice().

/*

  TOP 20 STRING INTERVIEW QUESTIONS — WITH ANSWERS

  Q1. Are strings primitive or reference types in JavaScript?
  ANS: Strings are PRIMITIVE types. They are stored by value, not by reference.
       However, you can still call methods on them because JS temporarily wraps
       them in a String object (auto-boxing) when a method is accessed.

  Q2. What is string immutability? Give an example.
  ANS: Once a string is created, its characters cannot be modified.
       str[0] = "X" silently fails. All string methods return NEW strings.
       Example:
         let s = "hello"; s[0] = "H"; console.log(s); // still "hello"

  Q3. How do you reverse a string in JavaScript?
  ANS: str.split("").reverse().join("")
       This splits into chars, reverses the array, and joins back.

  Q4. How do you check if a string is a palindrome?
  ANS: Clean the string (lowercase, remove non-alphanum), then compare with
       its reverse: clean === clean.split("").reverse().join("")

  Q5. What is the difference between slice() and substring()?
  ANS: slice() supports negative indices (counts from end).
       substring() does NOT support negative indices (treats as 0).
       If start > end: slice returns "", substring swaps them.
       Prefer slice() in modern code.

  Q6. What does indexOf() return when the substring is not found?
  ANS: -1. You check: if (str.indexOf(sub) !== -1). Alternatively, use
       str.includes(sub) which returns a boolean (cleaner and more readable).

  Q7. How do you convert a string to an array?
  ANS: Three ways:
       1. str.split("")       → array of chars
       2. [...str]            → spread operator
       3. Array.from(str)     → ES6
       For words: str.split(" ")

  Q8. How do you convert an array to a string?
  ANS: arr.join("")         → no separator
       arr.join(" ")        → space-separated
       arr.toString()       → comma-separated (calls join(","))

  Q9. What is the output of: "Hello".slice(1, 3)?
  ANS: "el" — characters at index 1 and 2 (index 3 is excluded).

  Q10. What is template literal / template string?
  ANS: Template literals use backticks (`) and support:
       - String interpolation: `Hello, ${name}`
       - Multi-line strings (press Enter inside backticks)
       - Embedded expressions: `${2 + 2}` → "4"
       - Tagged templates for custom processing

  Q11. What is the difference between includes() and indexOf()?
  ANS: includes() returns boolean (true/false) — use when you only need to
       know IF something exists. indexOf() returns the position (number) —
       use when you also need to know WHERE it is.

  Q12. How do you remove whitespace from both ends of a string?
  ANS: str.trim()       → removes from both sides
       str.trimStart()  → removes from the start (left)
       str.trimEnd()    → removes from the end (right)
       Very important for cleaning user input before processing/storing.

  Q13. What does split() with no argument do?
  ANS: "hello".split() returns ["hello"] — array with the whole string as
       the only element. "hello".split("") splits into individual characters.
       "hello world".split(" ") splits by spaces into words.

  Q14. How do you replace all occurrences of a substring?
  ANS: Two ways:
       1. str.replaceAll("old", "new")        — ES2021, string-based
       2. str.replace(/old/g, "new")          — regex with global flag
       For case-insensitive: str.replace(/old/gi, "new")

  Q15. What are the 6 falsy values? How does this relate to strings?
  ANS: false, 0, "" (empty string), null, undefined, NaN.
       An empty string "" is the ONLY falsy string value.
       All non-empty strings (including "false", "0", " ") are truthy.

  Q16. What is the difference between "==" and string comparison?
  ANS: "5" == 5 is TRUE (type coercion converts 5 to "5").
       "5" === 5 is FALSE (strict comparison — different types).
       String comparisons are CASE-SENSITIVE: "Hello" !== "hello".
       Always use === for string comparisons.

  Q17. How do you count the number of occurrences of a character in a string?
  ANS: Several ways:
       "banana".split("a").length - 1   → 3  (split creates n+1 pieces)
       [...str].filter(c => c === "a").length
       (str.match(/a/g) || []).length

  Q18. What does charCodeAt() do? How is it different from charAt()?
  ANS: charCodeAt(index) returns the NUMERIC Unicode code of the character.
       charAt(index) returns the actual CHARACTER at that index.
       charCodeAt is useful for range checks: A=65, Z=90, a=97, z=122, 0=48, 9=57.

  Q19. What is the output of "abc".repeat(-1)?
  ANS: It throws a RangeError: Invalid count value.
       repeat() requires a non-negative integer. repeat(0) gives "".

  Q20. What is String.fromCharCode() and how does it relate to charCodeAt()?
  ANS: They are INVERSES of each other:
       charCodeAt(index) → number (char to code)
       String.fromCharCode(code) → string (code to char)
       Example: "A".charCodeAt(0) === 65
                String.fromCharCode(65) === "A"
