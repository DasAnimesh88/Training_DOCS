/*
  Q1. What is the difference between type coercion and type conversion?
  ANS: Type coercion is implicit (automatic) — JS does it without being asked,
       e.g., "5" + 3 = "53". Type conversion is explicit — developer does it
       manually using Number(), String(), Boolean(), parseInt(), etc.

  Q2. What are the 6 falsy values in JavaScript?
  ANS: false, 0, "" (empty string), null, undefined, NaN
       Everything else is truthy, including "0", [], {}, -1, Infinity.

  Q3. What is the output of "5" - "3" and why?
  ANS: 2 (number). The - operator always tries to convert operands to numbers.
       "5" becomes 5 and "3" becomes 3, then 5 - 3 = 2.

  Q4. What is the output of "5" + 3 and why?
  ANS: "53" (string). The + operator with a string triggers string concatenation.
       3 is coerced to "3", then "5" + "3" = "53".

  Q5. What is the difference between parseInt() and Number()?
  ANS: parseInt() parses left-to-right, stops at first non-numeric character:
       parseInt("42px") = 42. Number() converts the entire string — if ANY
       non-numeric char exists, it returns NaN: Number("42px") = NaN.
*/

&&  AND  — returns first FALSY value, or last value if all truthy
  ||  OR   — returns first TRUTHY value, or last value if all falsy

// AND (&&)

How && works in JavaScript

The logical AND (&&) operator does not always return true or false.

It evaluates operands from left to right:

If it finds a falsy value, it returns that value immediately.
If all values are truthy, it returns the last value.
Step-by-step
5 && "hello"
5 is truthy
Since the first value is truthy, JavaScript evaluates the second value
"hello" is also truthy
All operands are truthy, so JavaScript returns the last operand

Result:

"hello"
More Examples
Example 1
console.log(0 && "hello");

Output:

0

Because 0 is falsy, JavaScript stops immediately and returns 0.

Example 2
console.log("abc" && 100);

Output:

100

Both values are truthy, so the last value is returned.

Example 3
console.log(null && "hello");

Output:

null

null is falsy, so evaluation stops there.
