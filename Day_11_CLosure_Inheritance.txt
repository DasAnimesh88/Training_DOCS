The super keyword in JavaScript is used to call methods and access properties of a parent class. It's primarily used in class inheritance scenarios.

Key Uses:
1. Calling Parent Constructor
class Animal {
  constructor(name) {
    this.name = name;
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);  // Calls parent constructor
    this.breed = breed;
  }
}
2. Calling Parent Methods
class Animal {
  speak() {
    return "Some sound";
  }
}

class Dog extends Animal {
  speak() {
    return super.speak() + " - Woof!";
  }
}

const dog = new Dog();
console.log(dog.speak()); // "Some sound - Woof!"
3. Accessing Parent Properties
class Animal {
  speak() {
    return "Some sound";
  }
}

class Dog extends Animal {
  speak() {
    return super.speak() + " - Woof!";
  }
}

const dog = new Dog();
console.log(dog.speak()); // "Some sound - Woof!"
Important Rules:
Must call super() first in a child constructor before using this
Only works in classes, not with prototype-based inheritance
Required in subclass constructor if the parent class has a constructor
Cannot be used outside of a class that extends another class
Since you're working on Day_11 (Closure & Inheritance), super is a key feature for modern class-based inheritance in JavaScript!

When the Parent class and Child class have a method with the same name, JavaScript invokes the Child class method.

Example from the image
class Person {
    eat() {
        console.log("eat");
    }

    sleep() {
        console.log("sleep");
    }

    work() {
        console.log("do nothing");
    }
}

class Engineer extends Person {
    work() {
        console.log("solve problems, build something");
    }
}

const engObj = new Engineer();

engObj.eat();    // inherited from Person
engObj.sleep();  // inherited from Person
engObj.work();   // overridden method
Output
eat
sleep
solve problems, build something
What happened?

Engineer inherits from Person.

class Engineer extends Person

Both classes contain a work() method:

// Parent
work() {
    console.log("do nothing");
}

// Child
work() {
    console.log("solve problems, build something");
}

When JavaScript finds engObj.work(), it first checks the Engineer class. 
Since Engineer already has a work() method, it uses that method and ignores the parent's version.

closure 

A Closure is created when a function remembers and can access
 variables from its outer function even after the outer function has finished executing.


Closure is a combination of a function and the lexical environment in which it was created. It allows the inner function to access variables of the outer function even after the outer function has completed execution.

Most Common Interview Question
function outer() {
    let x = 10;

    return function inner() {
        console.log(x);
    };
}

const myFunction = outer();
myFunction();

Output

10

Why?

Because inner() forms a closure and remembers x, although outer() has already finished executing.

One-line Memory Trick

Closure = Function + Remembered variables from its outer scope.



function createBankAccount(initialBalance) {
    let balance = initialBalance;

    return function deposit(amount) {
        balance += amount;
        console.log("Current Balance:", balance);
    };
}

const account = createBankAccount(1000);

account(500); // Current Balance: 1500
account(200); // Current Balance: 1700
account(100); // Current Balance: 1800


balance belongs to createBankAccount().
Even after createBankAccount() finishes, the returned function still remembers balance.
This remembering behavior is called Closure.
