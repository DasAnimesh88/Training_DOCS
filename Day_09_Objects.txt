### Accessing and Modifying Object Properties

**Question: Does person[name]="yadav" work?**
Answer: ❌ NO - This won't work as intended.

**The Problem:**
```javascript
person[name]="yadav"  // ❌ Incorrect - 'name' is treated as a VARIABLE, not a string
```
Since `name` is undefined, this actually does:
```javascript
person[undefined] = "yadav"  // Creates a property with key "undefined"
```

**What Actually Works:**

1. **Bracket Notation (with string key):**
```javascript
person["name"] = "yadav"  // ✅ Correct - updates name property to "yadav"
```

**⚠️ Important: Why can we modify a `const` object?**

`const` doesn't mean "immutable" — it means the **variable reference cannot change**. 
The object's **properties CAN be modified**.

```javascript
const person = { name: "Alice" };

// ✅ ALLOWED - modifying the property
person.name = "Bob";
person["age"] = 30;

// ❌ NOT ALLOWED - reassigning the variable
person = { name: "Charlie" };  // ❌ Error! Cannot reassign const variable
```

**How `const` works:**
- `const` **locks the reference** (prevents reassignment)
- `const` does NOT lock the **contents** of the object

```javascript
const arr = [1, 2, 3];
arr[0] = 99;        // ✅ OK - modifying array element
arr.push(4);        // ✅ OK - modifying array
arr = [5, 6, 7];    // ❌ Error - cannot reassign

const obj = { x: 10 };
obj.x = 20;         // ✅ OK - modifying property
obj.y = 30;         // ✅ OK - adding new property
obj = {};           // ❌ Error - cannot reassign
```

2. **Dot Notation:**
```javascript
person.name = "yadav"  // ✅ Correct - updates name property to "yadav"
```

3. **Bracket Notation (with variable):**
```javascript
let prop = "name";
person[prop] = "yadav"  // ✅ Works - the variable 'prop' contains the string "name"
```

**The Logic Behind It:**
- `person.name` → Direct property access using dot notation
- `person["name"]` → Bracket notation with STRING key (always use quotes)
- `person[name]` → Bracket notation with VARIABLE (looks up what the variable contains)

**Example:**
```javascript
console.log(person.name);     // "yadav" ✅
console.log(person["name"]);  // "yadav" ✅
console.log(person[name]);    // undefined ❌ (name variable doesn't exist)
```

**Important: Fix the method syntax:**
```javascript
// ❌ WRONG - don't use "let" inside object
let greet = () => { }

// ✅ CORRECT - use property: method syntax
greet() { }

## How to Access Object Properties and Methods

**1. Dot Notation (for properties):**
```javascript
const person = {
  name: "Alice",
  age: 28,
  city: "Mumbai"
};

console.log(person.name);   // "Alice"
console.log(person.age);    // 28
console.log(person.city);   // "Mumbai"
```

**2. Bracket Notation (for properties):**
```javascript
console.log(person["name"]);  // "Alice"
console.log(person["age"]);   // 28
console.log(person["city"]);  // "Mumbai"
```

**3. Calling Methods (functions inside objects):**
```javascript
const person = {
  name: "Alice",
  greet() {
    console.log("Hi, I'm " + this.name);
  }
};

person.greet();  // Output: "Hi, I'm Alice"
```

**4. Dynamic Property Access (with variables):**
```javascript
let prop = "name";
console.log(person[prop]);  // "Alice" - accesses person.name dynamically
```

**5. Accessing Nested Objects:**
```javascript
const person = {
  name: "Alice",
  address: {
    city: "Mumbai",
    country: "India"
  }
};

console.log(person.address.city);        // "Mumbai" - dot notation
console.log(person["address"]["city"]);  // "Mumbai" - bracket notation
console.log(person.address["city"]);     // "Mumbai" - mixed notation
```

**6. Modifying Properties:**
```javascript
person.name = "Bob";          // Using dot notation
person["age"] = 30;           // Using bracket notation
person.city = "Delhi";        // Add new property
```

**Key Differences:**
| Method | Syntax | Use Case |
|--------|--------|----------|
| **Dot Notation** | `person.name` | Simple, clean, most common |
| **Bracket Notation** | `person["name"]` | Dynamic keys, keys with spaces/special characters |
| **Methods** | `person.greet()` | Call functions inside objects (use parentheses) |

**When to Use Each:**
- Use **dot notation** for simple property names
- Use **bracket notation** when property names have spaces, special characters, or are dynamic (stored in variables)
- Always use **parentheses** when calling methods

## Higher Order Functions (HOF)

A **Higher Order Function** is a function that:
1. **Takes another function as an argument**, OR
2. **Returns a function**, OR
3. **Does both**

### Example 1: Function that takes another function as argument
```javascript
// Simple HOF - takes a function as argument
function greet(fn) {
  console.log("Hello!");
  fn();  // Call the passed function
}

function sayBye() {
  console.log("Goodbye!");
}

greet(sayBye);  
// Output: 
// Hello!
// Goodbye!
```

### Example 2: Function that returns another function
```javascript
// HOF that returns a function
function multiply(x) {
  return function(y) {
    return x * y;
  };
}

const double = multiply(2);
console.log(double(5));  // 10
console.log(double(8));  // 16
```

### Example 3: Array Methods (map, filter, reduce) - Built-in HOF
```javascript
const numbers = [1, 2, 3, 4, 5];

// map is a Higher Order Function (takes callback)
const doubled = numbers.map(num => num * 2);
// [2, 4, 6, 8, 10]

// filter is a Higher Order Function
const evenNumbers = numbers.filter(num => num % 2 === 0);
// [2, 4]

// reduce is a Higher Order Function
const sum = numbers.reduce((total, num) => total + num, 0);
// 15
```

### Example 4: Currying - Function that returns a function
```javascript
// HOF using currying
function add(a) {
  return function(b) {
    return a + b;
  };
}

const add5 = add(5);
console.log(add5(3));   // 8
console.log(add5(10));  // 15
```

### Example 5: Real-world - setTimeout is a HOF
```javascript
// setTimeout is a HOF - it takes a callback function
function myCallback() {
  console.log("Done!");
}

setTimeout(myCallback, 1000);  // Calls myCallback after 1 second
```

### Benefits of Higher Order Functions:
✅ **Code Reusability** - Write generic functions that work with different callbacks  
✅ **Composition** - Combine functions easily to create complex behaviors  
✅ **Abstraction** - Hide complex logic behind simple interfaces  
✅ **Functional Programming** - More elegant and maintainable code  

### Common HOF Patterns:
| Pattern | Purpose | Example |
|---------|---------|---------|
| **Callback** | Execute function after task | `setTimeout(fn, 1000)` |
| **Map** | Transform each element | `arr.map(fn)` |
| **Filter** | Select elements matching condition | `arr.filter(fn)` |
| **Reduce** | Combine all elements into one | `arr.reduce(fn)` |
| **Currying** | Create specialized functions | `const add5 = add(5)` |
```
