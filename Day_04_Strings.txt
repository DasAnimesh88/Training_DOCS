// Any operation that "changes" a string actually returns a NEW string
let original  = "hello";
let modified  = original.toUpperCase();  // returns a NEW string
console.log(original);   // "hello" — UNCHANGED
console.log(modified);   // "HELLO" — new string

let str = "Hello";
str[0] = "J";     // ❌ FAILS SILENTLY — strings are immutable!
console.log(str[0]);  // "H" — still unchanged

// Each character access is read-only
let word = "Playwright";
console.log(word[0]);     // "P"
console.log(word[1]);     // "l"
word[0] = "Z";            // silently ignored!
console.log(word);        // "Playwright" — unchanged


  Q1. Are strings mutable in JavaScript?
  ANS: "No. Strings are immutable — you cannot change individual characters
       after creation. Operations like toUpperCase(), replace(), etc. always
       return NEW strings. The original string remains unchanged."

indexOf() returns the index (number) of the first match, or -1 if not found.
       includes() returns a boolean (true/false).
       Use includes() when you only need to know IF something exists —
       it's more readable. Use indexOf() when you also need the position.

What does indexOf() return when the substring is not found?
  ANS: It returns -1. This is the standard check: if (str.indexOf(x) !== -1).
       However, str.includes(x) is cleaner for existence checks.
