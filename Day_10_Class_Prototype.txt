WHAT ARE PROTOTYPES?
==================
Prototypes are objects from which other objects inherit properties and methods.
Every JavaScript object has a prototype. When you access a property/method on 
an object, JavaScript first looks for it on that object. If not found, it looks 
on its prototype, then on the prototype's prototype, and so on. This is called 
the PROTOTYPE CHAIN.

KEY CONCEPTS:
- Every object has a prototype (internal [[Prototype]])
- Prototypes allow objects to inherit properties and methods
- The prototype chain enables inheritance
- Functions have a 'prototype' property used to create new objects

The Toyota class defines common properties and behaviors of all Toyota cars.

JavaScript Example
class ToyotaCar {

    constructor(model, color, price) {
        this.model = model;
        this.color = color;
        this.price = price;
    }
    setBrand(brand){
        this.brand=brand
    }

    start() {
        console.log(`${this.model} is starting`);
    }

    stop() {
        console.log(`${this.model} is stopping`);
    }

    displayDetails() {
        console.log(`Model: ${this.model}`);
        console.log(`Color: ${this.color}`);
        console.log(`Price: ₹${this.price}`);
    }
}

// Objects (Instances)
let fortuner = new ToyotaCar("Fortuner", "Black", 4500000);
let innova = new ToyotaCar("Innova Hycross", "White", 3000000);
let camry = new ToyotaCar("Camry", "Silver", 5000000);

fortuner.displayDetails();
fortuner.start();
fortuner.setBrand("Fortuner" )

      What is a Constructor?

A constructor is a special method inside a class that runs automatically 
whenever an object is created using new.

class MyClass {
    constructor() {
        console.log("Object Created");
    }
}

let obj = new MyClass();
Output
Object Created

The constructor ran automatically for both objects.

to initialize the object at object creation time

==================================

Why Constructor is Used

Without constructor:

class ToyotaCar {
}

let car1 = new ToyotaCar();

car1.model = "Fortuner";
car1.color = "Black";

With constructor:

class ToyotaCar {

    constructor(model, color) {
        this.model = model;
        this.color = color;
    }
}

let car1 = new ToyotaCar("Fortuner", "Black");//this initializes object
